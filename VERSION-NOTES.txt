AngelBot - Personal version / change notes
==========================================
For your own tracking only. Not an official changelog.

How to use
----------
- Hand-write entries anytime (newest first, under the separator below).
- Or enable auto-log on push (once per clone):  npm run notes:hooks
  Then each git push prepends date + commit subjects for the commits being pushed.
- Manual/sync without a push:  npm run notes:log
  (uses commits not yet on your upstream branch)

Auto-logged text comes from git commit messages. Edit any entry afterward.

Duplication: commit short SHAs already listed in this file are skipped.
